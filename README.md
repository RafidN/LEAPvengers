# Branching Strategy

We have chosen to use `trunk-based development`

### Reasons:
- Fewer long-lived branches allow for fewer total merges
- As a small team we can adapt to problems and deploy solutions quickly 
- Team stays aligned on the main codebase
- Continously Deployment-Ready
